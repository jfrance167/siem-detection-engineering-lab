# Security Policy

## ⚠️ Educational-use disclaimer

This repository contains code and evidence created for **educational and
training purposes only** as part of a cybersecurity portfolio. It models
hostile activity so that defensive detection and investigation techniques can
be practiced. All sample credentials, identities, hosts, IP addresses,
commands, and events are fictional, sanitized, or reserved for documentation.

This lab is not intentionally exploitable, but it is also not a production
SIEM. **Do not deploy this code as a production security control.** Do not use
the sample values as real credentials or configuration, and only analyze logs
from systems you own or are explicitly authorized to test.

If intentional vulnerabilities are added in the future, they must be clearly
marked `⚠️ VULNERABLE BY DESIGN` in the relevant file and README section.

## Reporting a security issue

Report genuine security issues privately through the repository's **Security →
Report a vulnerability** feature. Do not place credentials, tokens, private
logs, exploit details, or other sensitive evidence in a public issue.

Public issues are appropriate for ordinary bugs that contain no sensitive
information. This educational repository does not promise production support
or a formal response timeline.

## Scope

Examples of reportable issues include a real committed credential, unsafe
GitHub Actions behavior, or accidental publication of private evidence. The
fictional attack events and documented detection limitations are expected lab
content rather than security vulnerabilities.
